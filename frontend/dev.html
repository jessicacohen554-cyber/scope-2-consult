Component Harness

Every shared dashboard component, rendered from the hand-authored fixtures in data/fixtures/. Linked from nowhere; kept for smoke tests.
What this page is. A development harness for the shared infrastructure (P11): data-loader.js, segments.js, likert-viz.js, quote-cards.js, org-table.js and styles/site.css. It loads fixtures by default; append ?fixtures=0 to point the same components at the real exports in data/ once P22 has produced them.
