Component Harness

Every shared component of this hub, rendered from the hand-authored fixtures in data/fixtures/. Linked from nowhere; kept for smoke tests.
What this page is. A development harness for the shared infrastructure (P11): data-loader.js, segments.js, stance-viz.js, matrix-viz.js, quote-cards.js, org-table.js and styles/site.css. It loads fixtures by default; append ?fixtures=0 to point the same components at the real exports in data/ once P22 has produced them. Every number on this page is invented and every organization is fictional.

Stance strips

100% stacked horizontal bars in fixed meta option order, one n chip per strip. Q19 carries a polarity block, so it gets the support ramp with “No” as the critical answer; Q31 and Q45 have none, so they get the neutral sequential ramp. Special options are gray and hatched. Segment rows below the mask threshold are suppressed, never drawn as zero.

Additionality stringency matrix

Required / optional / not required is an ordered stringency ladder, so the ramp is sequential indigo and never the green/red support ramp (PLAN gotcha 5). Rows sort by net requiredness. Cells open a popover with the segment split.
